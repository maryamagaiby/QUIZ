# Quiz Project

A simple React quiz application built with Vite. The app loads trivia questions from the Open Trivia Database API, lets users answer multiple-choice questions, and shows their final score at the end.

## Features

- Home screen with a start button
- Dynamic quiz flow with multiple-choice questions
- Score calculation based on selected answers
- Results page with final score summary
- Responsive UI using Bootstrap
- Routing between pages using React Router

## Tech Stack

- React
- Vite
- Bootstrap
- React Router
- Open Trivia Database API

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Open the local URL shown in the terminal to use the app.

## Build

To create a production build:

```bash
npm run build
```
